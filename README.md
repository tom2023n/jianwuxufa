# 箭无虚发

一款点阵箭头迷宫解谜网页小游戏：棋盘上布满弯弯曲曲的箭头，点击箭头，若箭头朝向的方向一路畅通，它就会沿着自己的路径飞出棋盘；被挡住则会撞墙并扣一颗心。清空所有箭头即可过关。

> 受同类箭头消除玩法启发的非官方作品，与任何商业游戏无关。全部图形、图标、音效均由代码实时生成，不包含任何第三方素材。

## 在线游玩

- 网址：https://tom2023n.github.io/jianwuxufa/
- **iPhone**：用 Safari 打开 → 分享 → “添加到主屏幕”，即可像 App 一样全屏启动；首次打开后可离线游玩。
- **安卓 / 电脑 Chrome**：地址栏右侧“安装”图标即可安装。

## 玩法

- 三档难度：普通 / 困难（默认）/ 地狱，进度分别保存。
- 异形棋盘：方形、圆形、椭圆、心形、菱形、十字、沙漏、阶梯、星形、环形、回字、猫头、骷髅、小屋，共 14 种；箭头只占棋盘内的格子，挖空处不挡路，只要箭头朝向一路出界即可飞出。
- 难度曲线：困难约第 15 关到达最大棋盘（16 格宽，随屏幕自适应），之后箭头继续变长、弯折更多、开局可走的箭头更少、时间更紧，缓慢递增不封顶。
- 彩色箭头：10 色调色板（珊瑚红、金黄、草绿、青、天蓝、靛蓝、紫、粉、墨蓝、棕），相邻箭头不同色；彩虹箭头保持流动渐变。撞墙时箭头变红闪烁并加深色描边，提示为金色光圈。
- 心数 + 倒计时（地狱只有 2 颗心）；撞墙扣心，心用完或时间耗尽即失败。
- 连续成功发射会积累冲刺条（棋盘上下的线条），蓄满奖励分数和时间。
- 棋盘上偶尔出现 +5 秒时钟道具；从第 3 关起每 3 关出现彩虹箭头，可自动放飞多支可走的箭头。
- “提示”会高亮当前最值得先放飞的箭头。
- 所有关卡由种子随机生成，并保证一定有解；进度自动保存在本地。

## 技术

- 纯 HTML5 Canvas + 原生 JavaScript，单文件 `index.html`，无依赖、无构建。
- PWA：`manifest.json` + `sw.js`（缓存全部文件，离线可玩），所有路径为相对路径，可部署在任意子目录。
- 适配 iOS 刘海/底部安全区，禁止双击缩放与页面回弹。
- 性能（iPhone 主屏幕模式）：画布 DPR 上限 2；棋盘底板和点阵缓存到离屏画布；不使用逐帧 shadowBlur；空闲时降帧（游戏中 10fps 刷新倒计时，有动画才满帧；菜单 20fps）；尺寸事件去抖且只在尺寸真变时重建画布；切后台暂停、回前台恢复，带 rAF 看门狗。
- 更新：Service Worker 新版本安装后立即接管（skipWaiting + clients.claim），页面检测到后自动刷新一次。

## 界面

- 统一配色体系与字号层级，支持浅色 / 深色两套主题（菜单右上角切换，默认浅色，选择会被记住）。
- 主菜单：箭头 Logo、描边立体标题、分段式难度选择、呼吸动效的「开始游戏」大按钮、缓慢漂移的装饰箭头背景。
- 游戏中：胶囊卡片式 HUD（关卡 / 生命 / 得分）、渐变倒计时条、圆形图标按钮，纸张质感棋盘，适配刘海与底部安全区。
- 反馈：按钮按压缩放、连击徽章弹跳、过关彩带 + 星星依次弹出、卡片式过关 / 失败面板（主次按钮）。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```
