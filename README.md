# 箭无虚发

一款点阵箭头迷宫解谜网页小游戏：棋盘上布满弯弯曲曲的箭头，点击箭头，若箭头朝向的方向一路畅通，它就会沿着自己的路径飞出棋盘；被挡住则会撞墙并扣一颗心。清空所有箭头即可过关。

> 受同类箭头消除玩法启发的非官方作品，与任何商业游戏无关。全部图形、图标、音效均由代码实时生成，不包含任何第三方素材。

## 在线游玩

- 网址：`https://<你的用户名>.github.io/<仓库名>/`
- **iPhone**：用 Safari 打开 → 分享 → “添加到主屏幕”，即可像 App 一样全屏启动；首次打开后可离线游玩。
- **安卓 / 电脑 Chrome**：地址栏右侧“安装”图标即可安装。

## 玩法

- 3 颗心 + 倒计时；撞墙扣心，心用完或时间耗尽即失败。
- 连续成功发射会积累冲刺条（棋盘上下的线条），蓄满奖励分数和时间。
- 棋盘上偶尔出现 +5 秒时钟道具；从第 3 关起每 3 关出现彩虹箭头，可自动放飞多支可走的箭头。
- “提示”会高亮当前最值得先放飞的箭头。
- 所有关卡由种子随机生成，并保证一定有解；进度自动保存在本地。

## 技术

- 纯 HTML5 Canvas + 原生 JavaScript，单文件 `index.html`，无依赖、无构建。
- PWA：`manifest.json` + `sw.js`（缓存全部文件，离线可玩），所有路径为相对路径，可部署在任意子目录。
- 适配 iOS 刘海/底部安全区，禁止双击缩放与页面回弹。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 “Deploy from a branch”，分支 `main`、目录 `/ (root)`；
或选 “GitHub Actions”，使用自带的 `.github/workflows/pages.yml`。
